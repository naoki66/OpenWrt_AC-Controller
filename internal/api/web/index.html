周期重启

到点后控制器通过动作队列下发一条重启命令，与手动重启走同一条路径；离线 AP 会跳过本次， 下一个周期再排。时间为控制器本地时区。

状态 LED

立即开/关 AP 上名字含 status 的灯（XR1710G 为红/绿/蓝/白四色 status 灯）。 「开」只点亮绿色运行灯，其余颜色保持熄灭，避免 RGB 灯变白。 定时按控制器本地时区，到点经动作队列下发；离线 AP 跳过本次，下个周期再排。

AP 分组

分组把一批 AP 绑定到同一个模板。已采纳设备加入带模板的分组时立即生成下一版并下发； 待采纳设备只记录归属，采纳时默认使用分组模板（在采纳表单里显式选择的模板优先）。

重新下发

让 AP 按最新模板重新生成配置包并拉取；采纳状态不受影响。 模板改动对所有使用它的设备生效，但每台设备需各自触发一次。
