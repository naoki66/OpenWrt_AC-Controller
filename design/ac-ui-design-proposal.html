01

现状诊断

基于 index.html（5394 行，单文件 HTML + CSS + JS）逐层审阅。以下结论均可定位到具体样式规则或结构，不含主观审美判断。

A1
首屏信息过载，待办被淹没 高
「设备概览」页自上而下堆叠 6 张 KPI 卡 + 共享密钥面板 + 10 列设备表 + 周期重启 + 状态 LED + AP 分组 + 公钥说明。运维最需要立刻处理的「待采纳设备」只占一张普通 KPI 卡，与「控制器 ID」同权重，没有引导动作。
首屏只保留：待办横幅 → 4 张决策型 KPI → 设备表；其余设置折叠进「高级设置」。
A2
8 个平级导航，缺少任务分组 高
.nav a 为 8 个无差别链接，图标、分组、状态徽标全无；用户需要在「无线服务 / 射频管理 / 设备端口」之间靠文字反复辨认，扫描成本高。
按 监控 / 配置 / 系统 三组重排，加图标与待办计数。
A3
操作目标过小，主次按钮视觉权重倒置 高
button{padding:3px 10px;font-size:12.5px} 实际高约 22px，远低于 44px 触控下限；.primary 为暗蓝底 #17335c + 浅蓝字，与普通按钮 #1d232b 亮度接近，用户分不出「哪个是主操作」。
按钮统一 ≥32px（触屏 40px），主按钮改为实心品牌蓝 + 白字，次级降为描边。
A4
字号阶梯塌陷，长文本阅读吃力 中
全局正文 14px，但表格 th 12px / td 13px、说明文字 12px、面板说明 12px、表单标签 12px，大量关键说明落在 12–12.5px；h1 18px 与 panel h2 13px 仅差 5px，层级不明显。
建立 12/13/14/16/20/27px 阶梯，说明文字下限 13px，标题 22px。
A5
状态语义只靠颜色与文字，扫描效率低 中
四类 .badge 均为同形圆角胶囊，仅色相不同；.nav a.dim 颜色 #4b535e 在卡片上对比仅 2.24:1，禁用态几乎不可读。
状态统一「圆点 + 文字 + 语义色」三编码，禁用态对比提到 ≥3:1 并降低不透明度。
A6
缺少即时反馈与空/加载态 中
数值初始一律为 –，无骨架屏；操作结果只靠页面底部的 .msg 文本，长表格滚动后用户看不到反馈是否生效；.empty 只有一句灰字，无下一步引导。
引入 Toast、行内状态变化、骨架屏、带动作的空状态。
A7
无响应式与键盘可达性 高
全文件 无 @media，侧栏固定 200px、主区 max-width 1240px；除 VLAN 矩阵外所有表格在窄屏直接溢出。按钮无 :focus-visible，弹窗无 ESC 关闭与焦点管理，键盘用户无法判断当前焦点。
4 档断点 + 表格卡片化 + 全局焦点环 + ESC / 焦点陷阱。
A8
视觉层级偏平，缺少锚点 低
无图标系统、无阴影/高度层级、卡片与面板同为 #161a20 + 同圆角，页面像一张连绵的表格。
引入 24px 网格线性图标、3 级表面与 3 级圆角、可感知但克制的阴影。

02

设计原则

五条约束，后续所有组件与页面决策都以此为准绳；出现冲突时按序号优先。

① 状态优先

开机 3 秒内必须看到「有没有事要处理」。异常与待办占据首屏最高权重，正常信息降级为概览数字。

② 渐进披露

高频路径（查看 / 采纳 / 下发）保持一层；低频设置（密钥、重启计划、LED、NTP）收进折叠或抽屉，不挤占首屏。

③ 双编码，不靠颜色

状态、告警、趋势一律「形状/图标 + 文字 + 颜色」同时表达，色觉障碍与灰度打印下同样可读。

④ 每个动作有回音

点击后 100ms 内给出按下态，结果通过 Toast + 就地状态变化双重反馈；绝不静默失败。

⑤ 可逆与防误触

下发、重启、释放纳管等破坏性动作需二次确认并写明后果；确认按钮使用危险色，取消永远在左侧且可 ESC 退出。

⑥ 不重写业务逻辑

设计只替换 token 与组件层、增补结构容器；所有 id、API 调用、5 秒轮询与渲染函数保持原样，可分阶段灰度。

03

设计系统 · Foundation

以 4px 为基数的空间系统、双主题语义色、可验证的对比度。所有值以 CSS 自定义属性集中定义，改一处即可全局生效。

落地路线与验收

按风险从低到高拆成三阶段，每阶段都可独立上线并回滚；全程不改动任何 REST 调用与数据模型。

Phase 0 · 低风险

视觉层替换

  • 重写 :root 令牌与 [data-theme] 双主题
  • 替换 button / input / select / badge / card / table 组件规则
  • 字号阶梯、间距、圆角、阴影、图标 sprite
  • 补 :focus-visible、@media 四档断点
  • 不动任何 DOM id、class 名与 JS，可一处 diff 回滚
Phase 1 · 中风险

结构与反馈

  • 导航 3 组分组 + 图标 + 待办计数
  • 页头（面包屑 / 健康灯 / 刷新 / 主操作）
  • 待办横幅、KPI 精简、高级设置折叠
  • Toast、骨架屏、带动作的空状态、危险操作二次确认

  • 表格搜索 / 状态筛选 / 批量操作 / 列密度切换

  • 窄屏表格卡片化、抽屉导航、触控目标放大
  • 图表自适应与 reduced-motion
